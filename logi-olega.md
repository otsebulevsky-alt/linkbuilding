## Как дополнить экспорт до полного (все 1951 тред)

**Текущий статус:** обработаны батчи 0–10. На батче 11 MCP запросил повторную авторизацию Gmail — нужно заново авторизовать Google Workspace (Gmail) в Cursor, затем продолжить.

1. **Продолжить с батча 11:** для каждого батча с индексом 11, 12, …, 78 из `_batches.json` вызвать MCP `get_gmail_threads_content_batch` (user_google_email=`o.tsebulevsky@rantsports.com`, thread_ids=список из батча).
2. Если ответ записан в файл (agent-tools) — выполнить:  
   `python internal/seo/linkbuilding/scripts/append_batch_to_export.py <путь_к_файлу>`  
   Если ответ пришёл inline — сохранить его во временный файл и передать тот же скрипт.
3. После обработки батчей 11–78 в `logi-olega-export.txt` будет полная выгрузка всех прочитанных переписок (1951 тред).

## Как дополнять (другие источники)

Ниже или в отдельном файле можно добавлять переписки из других источников (мессенджеры, тикеты). Для удобства анализа желательно:

- Указывать **дату** (и при необходимости время) переписки.
- Указывать **источник** (Pachca, email, другой мессенджер).
- Указывать **контрагента/донора** (если применимо).
- Отделять блоки переписок горизонтальной чертой `---` или подзаголовком.

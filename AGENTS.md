# Linkbuilding — контекст для AI-агентов

## Назначение репозитория

Каноническое хранилище знаний команды Linkbuilding: соглашения, правила, инструкции, результаты тестов.

## Документирование

При запросе задокументировать, зафиксировать, записать что-либо — использовать скилл **linkbuilding-docs-route** (`.cursor/skills/linkbuilding-docs-route/SKILL.md`).

Агент сам определяет папку и формат. Сотрудник не должен разбираться в структуре.

## Структура docs

| Папка | Содержимое |
|-------|-----------|
| `docs/agreements/` | Договорённости, распределение зон |
| `docs/rules/` | Правила, конвенции |
| `docs/how-to/` | Инструкции, процессы, чеклисты |
| `docs/inbox/` | Неклассифицированное (fallback) |
| `learnings/` | Результаты тестов, гипотезы, кейсы |

## Связанные ресурсы

- `shared-docs/.../about-seo/docs/linkbuilding/` — отчёты, шаблоны доноров, onboarding
- `shared-docs/.../about-seo/functions/linkbuilding-outreach.md` — описание функции outreach
- `internal/seo/hide-linkbuilding-application-crm/` — LinkBuilder CRM

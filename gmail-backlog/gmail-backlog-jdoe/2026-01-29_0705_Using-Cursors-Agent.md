Cursor

Cursor Agent ( https://cursor.com/docs/agent/overview ) can take on complex coding tasks, such as creating features or fixing bugs end-to-end. You can use it in the sidepane with Cmd/Ctrl-I.

To get the most out of Agent, here are some tips:

*
Use “@” in your prompt ( https://cursor.com/docs/context/symbols#definitions ) to pull in specific context, such as specific files, websites, and git branches.
*
If you want to jump backwards in the Agent’s history, you can use checkpoints ( https://cursor.com/docs/agent/chat/checkpoints ) to revert changes.
*
Agent can run shell commands ( https://cursor.com/docs/agent/terminal ) as it works. You can also define command execution ( https://cursor.com/docs/agent/terminal#command-execution-modes ) rules.
*
With rules ( https://cursor.com/docs/context/rules#rules ) and /commands ( https://cursor.com/docs/agent/chat/commands ), you can configure system-level instructions and reusable workflows.
*
With cloud agents ( https://cursor.com/docs/cloud-agent ), you can spawn asynchronous agents that edit and run code in a remote environment.

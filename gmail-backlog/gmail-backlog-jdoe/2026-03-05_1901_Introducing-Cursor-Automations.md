Cursor now supports automations for building always-on agents.

Automations run on schedules or are triggered by events from Slack, Linear, GitHub, PagerDuty, and webhooks.

These agents can continuously monitor and improve your codebase by following your instructions and using the tools you've configured.

Automations use the tools you've configured

Try Automations ( http://cursor.com/automations )

We’ve found two categories of automations to be particularly useful:

*
Review and monitoring: Automations can catch and fix everything from style nits and inconsistencies to security vulnerabilities and performance regressions.
* Chores: Automations are great for everyday tasks and knowledge work like triaging bug reports, summarizing code changes, and adding test coverage.

Automations are great for handling chores

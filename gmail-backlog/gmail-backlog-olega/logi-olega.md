# Логи Олега

Выгрузка переписок для анализа.

**Назначение:** единый файл со всеми переписками, чтобы человек мог проанализировать содержание, контекст и результаты коммуникации.

---

## Источник

- **Почта:** o.tsebulevsky@rantsports.com (Gmail).
- **Фильтр:** только **прочитанные** письма (`is:read`); непрочитанные в выгрузку не входят.
- **Выгрузка:** 2026-03-10; поиск и сбор ID через Google Workspace MCP, получение тредов пачками по 25.

---

## Файлы

- **`logi-olega-export.txt`** — текст переписок (треды). Полная выгрузка: **все 79 батчей** (0–78), 1951 тред, ~5.5 MB, ~179k строк. Последнее обновление: 2026-03-11.
- **`all_read_thread_ids.txt`** — 1951 уникальный Thread ID по запросу `is:read` (все прочитанные на момент сбора).
- **`_batches.json`** — 79 батчей по 25 ID (последний — 1 ID) для вызова `get_gmail_threads_content_batch`.

---

## Как дополнить экспорт (если появятся новые треды)

**Текущий статус:** экспорт полный — обработаны все 79 батчей (0–78), 1951 тред.

Если нужно добавить новые прочитанные треды: обновить `all_read_thread_ids.txt` и `_batches.json`, затем для каждого нового батча вызывать MCP `get_gmail_threads_content_batch` и дописывать в экспорт через `append_batch_to_export.py` (путь к экспорту: `gmail-backlog/gmail-backlog-olega/logi-olega-export.txt`).

---

## Как дополнять (другие источники)

Ниже или в отдельном файле можно добавлять переписки из других источников (мессенджеры, тикеты). Для удобства анализа желательно:

- Указывать **дату** (и при необходимости время) переписки.
- Указывать **источник** (Pachca, email, другой мессенджер).
- Указывать **контрагента/донора** (если применимо).
- Отделять блоки переписок горизонтальной чертой `---` или подзаголовком.

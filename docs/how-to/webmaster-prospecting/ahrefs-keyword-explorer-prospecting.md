# Ahrefs: Keyword Explorer для проспектинга площадок

## Когда применять

- Нужно выйти на **редакционные и контентные** сайты через **семантику ниши**.
- Есть подписка **Ahrefs** (или доступ отдела).
- Задача — связать **поисковые запросы** с **SERP** и доменами в топе.

## Что понадобится

- Доступ к Ahrefs **Keywords Explorer**.
- Список базовых ключей или темы для расширения семантики.
- Уровень: **опытный**.

## Пошаговый процесс

### Шаг 1 — Собрать или развернуть семантику

1. Введите **сиды** (главные ключи ниши) в Keyword Explorer.
2. Изучите **Matching terms**, **Related terms**, кластеры; отфильтруйте по языку и стране.
3. Отметьте **информационные** и **коммерческие смешанные** запросы — они часто ведут к обзорам, медиа, блогам.

### Шаг 2 — Перейти от ключей к SERP

1. По выбранному ключу откройте **SERP overview** / список URL в топе.
2. Исключите агрегаторы, маркетплейсы, Wikipedia (если не целевой формат), одностраничные сервисы без блога.
3. Для перспективных URL отметьте **домен** и позицию.

### Шаг 3 — Квалифицировать домен под гестпост

1. Перейти на сайт: раздел блога, редакционная политика, контакты.
2. Проверить, публикуют ли **гостевой / экспертный** контент или только штатные авторы (второе не запрет, но меняется тон питча).

### Шаг 4 — Зафиксировать в реестре кандидатов

1. Домен, ключ, с которого пришли, URL примера страницы в топе, заметка о типе сайта (СМИ, блог, корпблог).

## Отбор и фильтры (квалификация)

| Критерий | Как проверить | Порог / правило «берём / не берём» |
|----------|----------------|-------------------------------------|
| Тематика / релевантность | Контент страниц из SERP по выбранному ключу | Высокое совпадение темы — приоритет. |
| Трафик / видимость | DR, organic traffic в Ahrefs по домену | Задать минимальные пороги по политике отдела. |
| Тип ссылки / индексация | Как конкуренты получают упоминания (обзоры, новости) | Оценить реалистичность гестпоста vs новость/PR. |
| Риски | Перепродажа места, шаблонные гостевые страницы | Признаки фермы — отсев. |
| Контакт | Editorial, общая почта, форма | Зафиксировать канал для outreach. |

## Типичные ошибки и обходные пути

- **Гнаться только за высокочастотными ключами** — в топе часто гиганты; использовать **long-tail** и нишевые формулировки.
- **Игнорировать намерение** — транзакционный SERP может не содержать подходящих доноров для статьи.
- **Не фиксировать исходный ключ** — потом сложно воспроизвести логику отбора.

## Ограничения и риски

- Данные Ahrefs с задержкой и оценочно; финальная проверка — **вручную**.
- Без доступа к Ahrefs метод **не применим** (см. SERP и конкурентов).

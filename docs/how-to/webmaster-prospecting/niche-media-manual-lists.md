# Ручной обход нишевых медиа и списков площадок

## Когда применять

- Нужны **качественные неочевидные** площадки вне топовой выдачи по операторам.
- Есть **отраслевые списки**: ассоциации, рейтинги СМИ, локальные каталоги, партнёры с отраслевыми подборками.
- Кампания **премиум** или узкая вертикаль (спорт, финтех, регион).

## Что понадобится

- Источники списков (отраслевые сайты, PDF, презентации партнёров, внутренние заметки).
- Время на **ручной** обход сайтов.
- Уровень: **опытный** (субъективная оценка качества медиа).

## Пошаговый процесс

### Шаг 1 — Собрать входные списки

1. Найти **кураторские подборки**: «лучшие блоги о…», члены ассоциации, медиа-партнёры событий.
2. Зафиксировать **источник списка** и дату (списки устаревают).

### Шаг 2 — Пройти каждый домен по чеклисту

1. Главная, раздел новостей/блога, страница **о редакции**, контакты.
2. Проверить, публикуют ли **внешний** контент, экспертные колонки, партнёрские материалы.

### Шаг 3 — Оценить «доступность» для outreach

1. Есть ли публичная политика гостевых / рекламных материалов.
2. Если нет — оценить **релевантность холодного** письма редактору (см. [negotiation-guide](../negotiation-guide.md)).

### Шаг 4 — Внести в реестр с пометкой источника

1. Домен, URL источника списка, краткий комментарий о типе медиа.

## Отбор и фильтры (квалификация)

| Критерий | Как проверить | Порог / правило «берём / не берём» |
|----------|----------------|-------------------------------------|
| Тематика / релевантность | Рубрики, последние публикации | Слабое пересечение — низкий приоритет. |
| Трафик / видимость | Общее впечатление + быстрая проверка в SEO-инструменте | Для премиум — выше требования к бренду и аудитории. |
| Тип ссылки / индексация | Как оформляют партнёрские материалы | Нужна совместимость с нашими требованиями к ссылке. |
| Риски | Политические/репутационные риски, жёсткая рекламная политика | Исключения по бренд-гайду компании. |
| Контакт | Редакционная почта, LinkedIn главреда | Прямой контакт ценится выше общей формы. |

## Типичные ошибки и обходные пути

- **Устаревшие списки** — домены мёртвы или сменили формат; проверять актуальность.
- **Только крупные имена** — теряются локальные сильные игроки; балансировать с long-tail медиа.
- **Нет записи источника** — потом нельзя воспроизвести отбор.

## Ограничения и риски

- Метод **трудоёмкий**, плохо масштабируется без команды.
- Субъективность оценки — полезно **двойное ревью** спорных площадок.

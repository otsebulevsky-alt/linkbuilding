# Холодный outreach по контактам с сайта (без публичной программы гостевых постов)

## Когда применять

- На сайте **нет** страницы «write for us», но есть **редакционный** контент или контакты.
- Площадка качественная, и есть гипотеза, что **индивидуальный** питч сработает.
- Уже есть **тема и ценность** для их аудитории (не шаблон «добавьте нашу ссылку»).

## Что понадобится

- Найденный **домен** и предпочтительный контакт (общая почта, редактор, форма).
- При необходимости инструменты **поиска email** (по политике компании и закону).
- Уровень: **опытный** (качество письма критично).

## Пошаговый процесс

### Шаг 1 — Собрать контакты со страницы

1. Страницы: Contact, About, Team, Advertising (иногда контакты рекламы ведут в редакцию).
2. Если только форма — зафиксировать ограничения (нет прямого email).

### Шаг 2 — Найти имя и роль адресата

1. По странице **Команда** выбрать редактора тематики или главреда.
2. Персонализация повышает ответ; избегать массовых «Dear webmaster».

### Шаг 3 — Составить короткое письмо

1. 1–2 предложения: кто вы, **почему им** (ссылка на их статью/рубрику).
2. Предложение: экспертный материал / коллаборация — **без** требования ссылки в первом сообщении (условия — на этапе ответа, см. [negotiation-guide](../negotiation-guide.md)).

### Шаг 4 — Отправить и зафиксировать в CRM/таблице

1. Дата, канал, адресат, статус (отправлено / ответ / тишина).
2. Напоминание через **7–10 дней** при отсутствии ответа (одно вежливое follow-up, не серия спама).

## Отбор и фильтры (квалификация)

| Критерий | Как проверить | Порог / правило «берём / не берём» |
|----------|----------------|-------------------------------------|
| Тематика / релевантность | Последние публикации, аудитория | Слабая связь — не тратить слот питча. |
| Трафик / видимость | Быстрая оценка через инструменты | Ниже порога — только если стратегическая ценность бренда. |
| Тип ссылки / индексация | После ответа — согласовать | Не обещать недостижимое в первом письме. |
| Риски | Жёсткий антиспам, юридические ограничения отрасли | Соблюдать CAN-SPAM/GDPR/локальные нормы. |
| Контакт | Валидность email, желательно персона | Нет персоны — общая редакционная почта. |

## Типичные ошибки и обходные пути

- **Шаблонные рассылки** — низкий ответ; уникальный абзац по сайту обязателен.
- **Сразу цена и ссылка** — сначала интерес редакции, условия после диалога.
- **Нет follow-up** — часть ответов теряется без одного напоминания.

## Ограничения и риски

- Риск пометки как **спам** — соблюдать объём, частоту, opt-out где применимо.
- Низкая конверсия — метод комбинировать с другими каналами проспектинга.

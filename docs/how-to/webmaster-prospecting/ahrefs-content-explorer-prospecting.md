# Ahrefs: Content Explorer для проспектинга площадок

## Когда применять

- Нужно найти сайты с **уже сильным контентом** по теме (статьи с трафиком/шерами).
- Есть **Ahrefs Content Explorer**.
- Цель — короткий список доменов с **доказанной контентной активностью** в нише.

## Что понадобится

- Доступ к Ahrefs **Content Explorer**.
- Ключевые фразы, бренды или URL-темы для поиска.
- Уровень: **опытный**.

## Пошаговый процесс

### Шаг 1 — Задать поиск по теме

1. В Content Explorer введите **фразу**, **тему** или набор слов на нужном языке.
2. Ограничьте **дату публикации** (например, последние 12–24 месяца), чтобы видеть актуальные площадки.

### Шаг 2 — Применить фильтры качества

1. **Domain Rating (DR)** — нижний порог по политике отдела (осторожно с завышением: можно потерять нишевые СМИ).
2. **Organic traffic** / **Referring domains** к странице — отсечь мёртвые URL.
3. Язык, тип контента (статья vs видео — по задаче).

### Шаг 3 — От страницы к домену и контактам

1. Откройте **топовые страницы** по метрикам; оцените качество редакции.
2. Перейдите на **домен**: разделы блога, страницы «О проекте», контакты, реклама/сотрудничество.
3. Запишите домен и **лучший аргумент для питча** (какая статья понравилась, почему релевантны мы).

### Шаг 4 — Дедупликация и приоритет

1. Один домен может давать несколько URL — в реестре держите **одну строку на домен** с ссылкой на пример статьи.
2. Пометьте источник: `CE: <запрос>` для трассировки.

## Отбор и фильтры (квалификация)

| Критерий | Как проверить | Порог / правило «берём / не берём» |
|----------|----------------|-------------------------------------|
| Тематика / релевантность | Заголовок и тело статьи в CE, рубрики сайта | Строгое попадание в тему или смежные вертикали. |
| Трафик / видимость | Метрики страницы и домена в Ahrefs | Минимум по внутренней шкале отдела. |
| Тип ссылки / индексация | Как сайт линкует внешние материалы | Проверить политику ссылок в гайдах. |
| Риски | Перегруженные «гостевые» хабы | Признаки ссылочной фермы — отсев. |
| Контакт | Email редакции, форма, LinkedIn | Нет контакта — другие методы поиска почты. |

## Типичные ошибки и обходные пути

- **Смотреть только на метрики страницы** — домен может быть хорошим, но не брать гостевые; проверять политику.
- **Слишком узкий запрос** — ноль результатов; расширять синонимы и смежные темы.
- **Пропускать дату** — в выборку попадают заброшенные проекты.

## Ограничения и риски

- Метрики **оценочные**; площадки с небольшим трафиком могут быть ценными в нише — не отсекать только по DR.
- Нужна действующая подписка Ahrefs.

# Поиск площадок через ссылки конкурентов

## Когда применять

- Есть 1–3 **сильных конкурента** в нише с видимым линк-профилем.
- Доступен **Ahrefs, Semrush или Majestic** (или бесплатные ограниченные отчёты).
- Нужны площадки, которые **уже размещали** похожий контент или ссылки в теме.

## Что понадобится

- Список конкурирующих доменов и/или конкретных URL их статей/лендингов.
- Доступ к инструменту **Backlinks / Referring domains**.
- Уровень: **опытный** (чтение отчётов по ссылкам).

## Пошаговый процесс

### Шаг 1 — Задать конкурента и тип отчёта

1. В Ahrefs (или аналоге): **Site Explorer** → домен конкурента → **Backlinks** или **Referring domains**.
2. Альтернатива: **Outgoing links** / **Linked domains** с **релевантной страницы** конкурента (где у них обзор/рейтинг в нише).
3. Ограничьте язык, тип ссылки (dofollow/nofollow), DR/Authority по задаче кампании.

### Шаг 2 — Фильтровать по признакам гостевого / редакционного размещения

1. Искать URL страниц **принимающей стороны**: блог, раздел новостей, «partners», а не главная с 500 исходящими.
2. Сортировать по **страницам с похожим анкором/темой** (guest, review, sponsored — уточнять по политике).
3. Исключать очевидные соцсети, маркетплейсы приложений, форумы без целевого размещения — если не входит в стратегию.

### Шаг 3 — Перейти на донора и проверить программу размещения

1. Открыть сайт донора: есть ли **guest / advertise / editorial**.
2. Зафиксировать контакт и условия (кратко в таблице кандидатов).

### Шаг 4 — Дедупликация и приоритет

1. Свести домены с нескольких конкурентов в одну таблицу без дублей.
2. Повысить приоритет доменам, которые встречаются у **двух+** конкурентов (сигнал рабочей площадки в нише).

## Отбор и фильтры (квалификация)

| Критерий | Как проверить | Порог / правило «берём / не берём» |
|----------|----------------|-------------------------------------|
| Тематика / релевантность | Контент страницы с нашей ссылкой у конкурента; тематика сайта | Берём при явной нише или смежной редакционной логике. |
| Трафик / видимость | DR/трафик в инструменте; выборочно Pages | Зависит от KPI кампании; слабые — в низкий приоритет. |
| Тип ссылки / индексация | Атрибуты ссылки, индекс страницы | Sponsored/guest по правилам Google — соблюдать маркировку. |
| Риски | Много исходящих ссылок с одной страницы, однотипные сайты | Подозрение на ферму — отсев или ручная проверка. |
| Контакт | Страница контактов, LinkedIn редакции | Нет контакта — искать через другие способы или отложить. |

## Типичные ошибки и обходные пути

- **Смотреть только на домен без страницы** — важен контекст страницы, где стояла ссылка.
- **Копировать весь список подряд** — без фильтра получится сотни нерелевантных доменов.
- **Один конкурент** — лучше агрегировать 2–3 источника для ширины выборки.

## Ограничения и риски

- Конкуренты могут использовать **закрытые сети** — не все ссылки видны в паблик-отчётах.
- Часть ссылок — **купленные пакеты**; качество нужно проверять вручную.

# Переговоры с донорами

## Когда применять
При первом контакте с новым донором и при согласовании условий размещения.

## Шаги
1. Проверить метрики донора (DA, трафик, тематика)
2. Написать первое письмо — представление + предложение
3. При ответе — уточнить условия: цена, количество ссылок, тип контента
4. Спросить: сколько hops от главной до страницы со статьёй?
5. Если разрешают 2 ссылки — предложить вариант с двумя
6. При отказе — использовать rejection-handling процесс
7. Зафиксировать условия в docs/agreements/

# Linkbuilding Docs

Каноническое хранилище соглашений, правил и инструкций команды Linkbuilding.

## Структура

| Папка | Что хранится | Когда использовать |
|-------|-------------|-------------------|
| `agreements/` | Договорённости, распределение зон | «Мы договорились, что…», «Кто за что отвечает» |
| `rules/` | Правила и конвенции | «Так надо делать», «Нельзя…», «Обязательно…» |
| `how-to/` | Инструкции, процессы, чеклисты | «Как мы делаем…», «Процесс переговоров» |
| `how-to/webmaster-prospecting/` | Способы поиска и отбора вебмастеров/площадок (один способ = один `.md`) | «Как находим вебмастеров», «проспектинг», «где ищем доноров», пошаговый способ с отборами |
| `inbox/` | Неклассифицированное (временно) | Агент не определил категорию |

## Learnings

Результаты тестов, гипотезы, кейсы — в отдельной папке `../learnings/`.

## Как добавлять

Сотрудник описывает задачу в Cursor — агент сам определяет папку и формат.
Скилл: `linkbuilding-docs-route`.

Примеры запросов:
- «Задокументируй: мы договорились, что Elena ведёт контент по тематике X»
- «Зафиксируй правило: спортивные новости → спортивные доноры»
- «Добавь инструкцию по переговорам с донорами»
- «Результат теста: evergreen лучше конвертит на всех донорах»
